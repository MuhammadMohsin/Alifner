Privacy Policy

ALIFNER Social Publisher

Effective Date: November 9, 2026

1. Introduction

ALIFNER Social Publisher is a personal application used to manage and publish promotional content for the ALIFNER e-commerce brand. This Privacy Policy explains how the application handles information when publishing content to Pinterest.

2. Information We Process

The application may process Pinterest authentication tokens, Pinterest board IDs, product images, product titles, descriptions, keywords, Etsy product links, publishing results, and error logs.

The application is not designed to collect information from ALIFNER customers or website visitors.

3. How We Use Information

Information is used to:

  • Authenticate with Pinterest.
  • Create and publish Pinterest Pins.
  • Promote ALIFNER products and Etsy listings.
  • Manage publishing schedules.
  • Monitor publishing status and errors.

4. Pinterest Integration

When a Pin is published, the application may send its image, title, description, keywords, and destination link to Pinterest. Pinterest handles this information under its own privacy policy.

Pinterest Privacy Policy

5. Storage and Security

The application may run through GitHub Actions. Pinterest credentials and tokens should be stored using GitHub Actions secrets and should not be committed to source code.

Reasonable security measures are used to protect credentials and publishing information.

6. Third-Party Services

The application may use:

  • Pinterest API for publishing content.
  • GitHub repositories and GitHub Actions for application code and execution.
  • AI image-generation services when enabled.

These services operate under their own terms and privacy policies.

7. Sharing

ALIFNER does not sell or rent personal information. Information is shared with third-party services only when necessary to publish content or operate the application.

8. Retention and Revoking Access

Publishing records and application logs may be retained for operational purposes.

Pinterest access can be revoked through Pinterest account settings. Stored tokens should be removed from GitHub secrets when they are no longer needed.

9. Children's Privacy

This application is intended for business and personal content management. It is not designed to collect information from children.

10. Policy Changes

This Privacy Policy may be updated if the application's functionality or data handling practices change. The latest version will be published on this page.
